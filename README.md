# Weather Trends Analysis

## Overview
Simple analysis of daily weather data to identify trends and basic statistics over time.

## Dataset
- File: data/weather_daily.csv
- Rows: 180
- Features: date, avg/min/max temp, humidity, precipitation, wind, pressure

## Analysis
- Time series trend analysis
- Correlation between weather variables
- Distribution and summary stats

## Technologies
- Python
- pandas, numpy
- matplotlib, seaborn
- Jupyter Notebook

## Getting Started
`ash
pip install -r requirements.txt
jupyter notebook notebooks/weather_trends_analysis.ipynb
`

## Key Findings
- Clear temperature trends over the observed period
- Humidity and precipitation relationships observed
- Descriptive stats reveal seasonal patterns
